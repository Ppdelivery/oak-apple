Starting over

Setting the app up fresh after the second code has been used.

What happened

When the second code is entered, Oak apple erases everything you had kept behind it and returns to the plain home screen a new phone shows — no code, no arrangement, nothing to say it was ever set up.

That is the whole point of it. A phone handed over under pressure should look like one nobody has touched, not one that has visibly just reset itself in someone's hand.

There is no way back in from inside the app, and that is deliberate. A screen asking you to choose a new code, appearing the instant the second code was entered, would tell the person in front of you exactly what that code just did. So the app does not offer one. Starting again is something you do later, on your own, in one of two ways.

Reset it in Settings — no connection needed

You do not need to download anything, and this works anywhere — with no signal, on a plane, in a place with no way to reach the Play Store. Android can clear the app back to a fresh state entirely on its own:

Settings → Apps → Oak apple → Storage → Clear data On a Samsung phone: Inställningar → Appar → Oak apple → Lagring → Rensa data

Clearing the data empties the app to how it was the first time you opened it. Open Oak apple afterwards and it starts at the setup screen, ready to set up again.

It is Clear data that resets it, not Clear cache. Clearing the cache on its own changes nothing here.

Or install it again from Google Play

If you would rather, uninstall Oak apple and install it again:

Oak apple on Google Play

A fresh install opens at the same setup screen. This route needs a connection, which is why the reset above is the one to reach for when you have none.

An update from the Play Store is not enough on its own — updating keeps the app's data, so it stays in the plain, already-used state. It has to be removed and installed again, or reset the way above.

After either

Open the app, choose your code, and set it up again — move what you want kept behind it, and set a second code if you use one. Nothing carries over from before. It is a clean start every time, which is the same reason it could not be undone from the inside.
